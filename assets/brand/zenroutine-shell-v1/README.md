# ZenRoutine shell brand v1

Start with [the visual preview](preview/index.html), [brand guide](BRAND-GUIDE.md), and [implementation prompt](IMPLEMENTATION-PROMPT.md).

This is a production asset kit and specification, not an applied app redesign. SVG masters, PNG exports, local fonts with licence, theme tokens, splash concepts and the 1200 × 630 social image are included. The original approved bitmap is retained under `source/` for provenance. Use current assets under this directory rather than earlier concepts in `output/`.
